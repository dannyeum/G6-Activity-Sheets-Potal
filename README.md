# 🗺️ 6학년 활동지 학습맵 — 교수학습 포털 사용 설명서

5~6학년군 성취기준 254개를 한눈에 보고, 인터랙티브 활동지 146개를 찾아 **온라인으로 배포**하거나 **인쇄**하는 교사용 포털이에요.
서버 없이 돌아가요. 폴더째 올리기만 하면 돼요.

## 📁 폴더 구성

```
index.html            ← 포털 첫 화면
assets/               ← 포털 디자인(portal.css)·기능(portal.js)·QR 만들기(qrcode.js, MIT)
data/
  catalog.json        ← 활동지 146개 정보
  standards.json      ← 성취기준 254개 (made: 활동지 있음)
  subjects.json       ← 과목 이름·색·영역 이름
  bundle.js           ← 위 세 파일을 합친 것 (자동 생성)
worksheets/{과목}/     ← 활동지 HTML 파일들
tools/                ← 목록 자동 갱신 스크립트
PROMPT_교수학습포털_웹앱.md ← 이 포털의 설계 프롬프트
```

## 🚀 배포하기 — GitHub Pages (무료, 5단계)

1. https://github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **＋ → New repository**를 눌러요. 이름(예: `activity-portal`)을 쓰고, **Public**을 골라 만들어요.
3. **uploading an existing file**을 눌러요. 이 폴더 안의 **모든 파일과 폴더**를 끌어다 놓고 **Commit changes**를 눌러요.
   한 번에 100개까지 올라가니 `worksheets` 폴더는 과목 폴더별로 나눠 올려도 돼요.
4. **Settings → Pages → Branch: main / (root) → Save**를 눌러요.
5. 1~2분 뒤 `https://내아이디.github.io/activity-portal/` 주소로 포털이 열려요. 🎉

> 학교 홈페이지 웹 폴더나 Netlify(폴더를 끌어다 놓기)에 올려도 똑같이 작동해요.
> 선생님 PC에서만 볼 때는 `index.html`을 더블클릭해도 열려요.
> 다만 학생 배포용 링크와 QR은 **웹 주소(https://)로 올린 뒤** 만들어야 학생 기기에서 열려요.

## 👩‍🏫 이렇게 써요

| 메뉴 | 하는 일 |
|---|---|
| 🗺️ **학습맵** | 과목 × 영역별 성취기준 지도를 봐요. 색 칩은 활동지 있음, 점선 칩은 준비 중이에요. 칩을 누르면 상세 화면이 열려요. 과목 막대를 누르면 그 과목을 크게 보여 줘요. 🖨️ 버튼으로 A4 가로 한 장에 인쇄할 수 있어요. |
| 🔎 **활동지 찾기** | 검색어(`/` 키), 과목, 영역, 활동 유형(듣기·작곡·실험 등)으로 찾아요. |
| 📄 **상세 화면** | 성취기준 원문, 학생 목표, 개념, 활동 구성을 보고 실제 활동지를 미리 봐요. 아래 버튼으로 학생용 링크 복사, QR 크게 보기, 인쇄, 진도표·수업 세트 담기를 해요. |
| 📅 **내 진도표** | 주차별로 활동지를 배치해요(끌어 옮기기, ◀ ▶). ‘수업함’을 체크하면 학습맵에 ✅가 표시돼요. CSV·JSON으로 동학년 선생님과 주고받을 수 있어요. 엑셀에서 `주차 / 과목 / 성취기준코드 / 메모`를 복사해 붙여 넣으면 자동으로 배치돼요. |
| 🎒 **수업 세트** | 활동지 최대 6개를 골라 **링크 하나**로 학생에게 나눠 줘요(QR 가능). 학생은 고른 활동지만 큰 카드로 보고 바로 활동해요. |

### 🧒 학생 화면에서는
- 수업 세트 링크로 들어오면 교사 메뉴가 숨겨지고 **오늘의 활동 카드**만 보여요.
- 카드를 눌러 활동하고, **⬅ 오늘의 활동으로 돌아가기**로 돌아와요.
- 활동지에서 **💾 결과 저장**을 하면, 그 기기의 카드에 **✅ 저장 완료**가 표시돼요.

### 💾 저장에 대해
- 진도표와 수업 세트는 **선생님 기기(브라우저)**에 저장돼요. 다른 PC로 옮길 때는 JSON 내보내기·가져오기를 써요.
- 학생 결과는 지금처럼 활동지의 **결과 저장(.txt)**이나 **인쇄/PDF**로 제출받아요.

## ➕ 새 활동지 추가하기

1. 새 활동지 파일을 `worksheets/과목폴더/`에 넣어요.
   - 과목 폴더: `kor` 국어, `math` 수학, `soc` 사회, `sci` 과학, `eng` 영어, `moral` 도덕, `prac` 실과, `music` 음악, `art` 미술
   - 파일 이름 형식: `6과07-01_온도재기_활동지.html` (성취기준코드_짧은이름_활동지.html)
2. 포털 폴더에서 아래를 실행해요(파이썬 3 필요).
   ```
   python tools/build_catalog.py     # 목록·성취기준 갱신 + bundle.js 자동 생성
   python tools/check_links.py       # 모든 링크가 열리는지 확인
   ```
3. 바뀐 `data/` 폴더와 새 활동지를 GitHub에 다시 올려요. 학습맵에서 그 칩이 ‘준비 중’에서 색 칩으로 바뀌어요.

## 🛠️ 바꾸고 싶을 때

- **학교 이름, 기본 주차 수, 수업 세트 최대 개수**: `assets/portal.js` 맨 위 `SETTINGS`
- **과목 색·영역 이름**: `data/subjects.json`을 고친 뒤 `python tools/make_bundle.py` 실행
- **전자칠판에서 글자를 크게**: 오른쪽 위 🖥️ 버튼

## ❓ 자주 묻는 질문

- **QR이 안 만들어져요.** 수업 세트에 활동지가 너무 많거나 안내 문구가 길면 주소가 길어져요. 문구를 줄여 주세요.
- **인쇄 창이 안 떠요.** 브라우저가 팝업을 막았을 수 있어요. ‘새 탭에서 열기’ 후 활동지 맨 아래 🖨️ 인쇄 버튼을 눌러 주세요.
- **활동지 결과를 포털에서 모아 볼 수 있나요?** 지금 버전은 서버 없이 작동해서 모으지 않아요. 다음 단계로 Google Apps Script나 Firebase 연동을 추가할 수 있어요.
